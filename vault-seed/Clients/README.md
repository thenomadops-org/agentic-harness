# Clients

One directory per client. This is the wiki, and it grows as a side effect of
doing the work rather than as a documentation project someone is assigned.

```
Clients/<slug>/<slug>-Home.md    the client's index — link everything from here
Clients/<slug>/...               pages, added as things are learned
```

**The rule:** when an agent learns something about a client that outlives the
ticket, it becomes or updates a page here and links the memory atom carrying
the lesson. Tickets are episodic and vanish into a closed board; this is what
remains.

Link every page from the client home. An orphan page is one retrieval will
never reach — correct, complete, and invisible.

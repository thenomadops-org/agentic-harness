# Memory

Two scopes, and mixing them fails in both directions.

```
_shared/      lessons that travel — how work goes wrong in general
<client>/     facts about one client's cluster, board, product
```

A client fact in `_shared` pollutes every other engagement. A general lesson
filed under one client gets learned again on the next.

Each scope has a `MEMORY.md` index. An atom not linked from its index is an
orphan: it exists, it is correct, and it will never fire.

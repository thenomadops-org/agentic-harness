# Owner interface

**Originator:** the principal
**Recorded:** 2026-10-25, transcribed 2026-10-26. The transcript named one chat
client. That product name is omitted below so this page does not bind the role
to a vendor. The sentence is otherwise the principal's, spelling included.
**Status:** ACTIVE

## Problem

The principal wants one chat for updates, for starting work, and for opening
stories:

> "for myself I am going to use a chat bot to interact with the getting updates and starting new work or opening new storys"

The words "a chat bot" stand where the transcript named a product. The rest of
the sentence is unchanged.

## Desired outcome

The principal describes work in that chat, says when it may start, and asks for
updates there. The principal does not have to chase each session, and the chat
in front of the principal can be replaced by another one.

## Constraints

- Another chat front end can play the same role.
- The tracker stays the adapter the org already chose.
- An agent that cannot move the tracker still has a way to ask for the move.
